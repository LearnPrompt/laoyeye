# 问清问题

只有知道自己真正想问的是什么，才有后面的一切。

## 模型可唤起

你说到相关的事，Agent 自己就会拿出来用。

- **[苏格拉底式提问](./socratic-inquiry/SKILL.md)**（`socratic-inquiry`）：先别急着要答案，让它把你真正该问的那个问题问出来。
- **[拷问 grilling](./matt-grilling/SKILL.md)**（`matt-grilling`，收录自 mattpocock-skills）：决策树走空为止的无限拷问，苏格拉底那条最多六问就收，这条不收。

## 只有你能唤起

太长太黏人，只有你亲口叫它才出现。

- **[拷问我 grill-me](./matt-grill-me/SKILL.md)**（`matt-grill-me`，收录自 mattpocock-skills）：上面那条的用户唤起版，敲了才出现。
