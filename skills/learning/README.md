# 学习

面对一个陌生的东西，四种需求，四条路。想真学下来而不是听懂一次，还有第五条。

## 模型可唤起

你说到相关的事，Agent 自己就会拿出来用。

- **[双层解释法](./two-layer-explain/SKILL.md)**（`two-layer-explain`）：小白版和专业版各讲一遍，别停在好像懂了。
- **[反向拆解](./reverse-teardown/SKILL.md)**（`reverse-teardown`）：看到一个牛逼的成品，把它为什么牛逼拆出来。
- **[横纵分析法](./horizontal-vertical-analysis/SKILL.md)**（`horizontal-vertical-analysis`）：纵轴看它怎么走到今天，横轴看它跟对手差在哪。
- **[事实核查](./fact-check/SKILL.md)**（`fact-check`）：把事实、推论、价值判断拆开，一条条验。

## 只有你能唤起

太长太黏人，只有你亲口叫它才出现。

- **[教 teach](./matt-teach/SKILL.md)**（`matt-teach`，收录自 mattpocock-skills）：跨会话把一门东西真学下来，留下课件和速查表，学习那节其余四条都是单次的。
