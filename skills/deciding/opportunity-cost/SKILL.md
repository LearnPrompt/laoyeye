# 机会成本与可逆性

适合手上好几件事不知道先干哪件，或者一件事纠结做还是不做。每个选项都过三个问题：做了放弃什么，做错了能不能退回来，不做会怎样。能退回来的双向门就快定，退不回来的单向门才放慢。

双向钢人只吃两个选项，最小实验管验证不管排序，这条补的就是这块。

## 怎么用

下面代码块里的提示语是原文，逐字使用。代码块里的「我」指用户，「请你」「你」指你自己，照它做事，不要把填好的提示语打给用户看。

- 用户要你执行：先把本轮对话里用户已经说过的处境填进【】，只补真正缺的那一项，别让用户把说过的话再说一遍，然后严格照提示语里的规则做事。它说先别给建议就先别给，说一次只问一个问题就一次只问一个，说按顺序输出就按那个顺序输出。
- 用户要原文（明确说要复制、要粘贴、发我原文、给我提示语这类话才算）：打空白版，【】保持不填，一个字不改。用户只是说「看看这条提示语」「这条是干嘛的」，不算要原文，用一两句说清它干什么、什么时候用，再问要不要现在跑，别直接倒原文。
- 除了明确要原文的情况，其余一律当执行处理。

禁止改写、精简、扩写、翻译、重排、加小标题，禁止把它替换成你自己的流程，也禁止把多轮追问压缩成一次性问卷。用户手上有原始材料（文档、截图、链接、聊天记录）就一并读进来，上下文多不是问题。

## 跑完接哪条

排到最后只剩两个都有道理、分不出先后的，用 Skill 工具唤起 `steelman-both-sides`；排第一的那件是单向门、缺的信息靠想补不上，用 Skill 工具唤起 `minimum-experiment` 让现实回答；第一件定了要派给 agent 干，用 Skill 工具唤起 `kaz-leader`。

```markdown
我现在面对的选择是：【写下你在纠结的事，可以是「做还是不做」，也可以是一串不知道先做哪件的事】。
我手上的约束是：【时间、钱、精力、人手，哪样最紧就写哪样】。

请帮我用机会成本和可逆性把这些事过一遍，排出先后。

第一步，把每个选项（包括「什么都不做」）单独列出来。每一项回答三个问题：
1. 做了它，我要放弃什么？写具体的东西，比如「这周不能写方案了」，不要写「会占用时间」。
2. 做错了能不能退回来？能低成本退回来的算双向门，退不回来或者退回来很贵的算单向门。说清楚退回来要花什么。
3. 不做它，接下来一个月会发生什么？会不会有东西变坏、有机会关上？还是其实什么都不会发生。

第二步，按下面的规矩给每一项定节奏：
- 双向门：信息够七成就定，别再开会讨论，先做了再说。
- 单向门：放慢，先列出还缺哪几条信息，补齐再定。
- 不做也没什么后果的：直接划掉，或者放进以后再说的清单。

第三步，排出先后顺序，说明排序靠的是哪一条理由。

最后请输出：
1. 一张表：选项、放弃什么、双向门还是单向门、不做的后果、节奏；
2. 排好的先后顺序，第一件写清楚今天就能开始的那个动作；
3. 这次我最可能高估的一件事和最可能低估的一件事。
```

## 用户要填的位置

- `【写下你在纠结的事，可以是「做还是不做」，也可以是一串不知道先做哪件的事】`
- `【时间、钱、精力、人手，哪样最紧就写哪样】`

用户没给全就先问缺的那一条，别自己替他编。
