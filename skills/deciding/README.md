# 决策

两个答案都有道理的时候，你还是得选一个。

## 模型可唤起

你说到相关的事，Agent 自己就会拿出来用。

- **[双向钢人论证](./steelman-both-sides/SKILL.md)**（`steelman-both-sides`）：两个选项都有道理的时候，把两边都论证到最强。
- **[最小实验](./minimum-experiment/SKILL.md)**（`minimum-experiment`）：别再推演了，花七天真跑一次，让现实给你数据。
- **[机会成本与可逆性](./opportunity-cost/SKILL.md)**（`opportunity-cost`）：每件事先问放弃什么、能不能退回来、不做会怎样，再排先后。
- **[执行意图](./implementation-intention/SKILL.md)**（`implementation-intention`）：事情已经定了却开不了头，写成如果碰到什么、我就做什么。
