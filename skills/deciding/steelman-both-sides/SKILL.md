# 双向钢人论证

跟问清问题那一条的分工不一样：那条是帮你把问题提对，这条是你已经有答案了、不知道选哪个的时候拿来做决策。

它先重述你真正要做的选择，再分别给两个方向最强的理由、适用条件、最大收益、最大风险和最难回答的反对意见，最后只问你一个最可能改变结论的问题。

## 怎么用

下面代码块里的提示语是原文，逐字使用。代码块里的「我」指用户，「请你」「你」指你自己，照它做事，不要把填好的提示语打给用户看。

- 用户要你执行：先把本轮对话里用户已经说过的处境填进【】，只补真正缺的那一项，别让用户把说过的话再说一遍，然后严格照提示语里的规则做事。它说先别给建议就先别给，说一次只问一个问题就一次只问一个，说按顺序输出就按那个顺序输出。
- 用户要原文（明确说要复制、要粘贴、发我原文、给我提示语这类话才算）：打空白版，【】保持不填，一个字不改。用户只是说「看看这条提示语」「这条是干嘛的」，不算要原文，用一两句说清它干什么、什么时候用，再问要不要现在跑，别直接倒原文。
- 除了明确要原文的情况，其余一律当执行处理。

禁止改写、精简、扩写、翻译、重排、加小标题，禁止把它替换成你自己的流程，也禁止把多轮追问压缩成一次性问卷。用户手上有原始材料（文档、截图、链接、聊天记录）就一并读进来，上下文多不是问题。

## 跑完接哪条

最后那个关键问题靠想答不出来，用 Skill 工具唤起 `minimum-experiment` 让现实回答。

```markdown
我需要做的决定是：【写清问题、两个选项、目标和现实约束】。

先别急着回答，也别默认我已经把问题想清楚。请先做一次双向钢人论证：

1. 用最完整、有力的方式，重述我真正需要做出的选择；
2. 分别给出支持两个方向的最强理由、适用条件、最大收益、最大风险，以及最难回答的反对意见；
3. 找出双方真正的分歧、最可能改变结论的关键变量，以及还需要补充的信息；
4. 只问我一个最可能改变结论的问题。

等我回答以后，再给出明确判断、理由、适用条件和下一步行动。
```

## 用户要填的位置

- `【写清问题、两个选项、目标和现实约束】`

用户没给全就先问缺的那一条，别自己替他编。
