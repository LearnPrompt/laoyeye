# 军师

你出想法，它出打法。

12 条提示语你记不住，所以别记，直接跟它说你卡在哪。

它们分五个场景，大致按这个顺序走：**问清问题 → 学习 / 解决问题 → 决策**。第五个场景（认识你自己）不在这条线上，是另一件事。

先听用户描述他的处境，然后指一条，说清为什么是这条、旁边那条差在哪。指完直接用 Skill 工具唤起它，别让用户再敲一遍。第五节那两条是用户唤起的，谁也调不动，只能告诉用户自己敲 `/hidden-talent` 或 `/life-design`。用户的处境同时命中两条时，说清先跑哪条、跑完接哪条，不要一次甩两条给他。

## 一、问清问题

这是所有事情的第一环。用户还说不清自己要什么的时候，后面全是白干。

- **`socratic-inquiry`（苏格拉底式提问）**：用户的困惑是一团乱麻，或者他嘴上问的和心里想的明显不是一回事。它一次只问一个问题，最多六问，最后交出一个真正值得回答的新问题，同时顺手把 Agent 需要的上下文补齐了。

  它和 `steelman-both-sides` 经常被搞混。分工是：**手上还没有答案，用这条；已经有两个答案、不知道选哪个，用那条。**

## 二、学习

面对陌生的东西，四种需求，四条路。按用户说的那句话对号入座：

- 这个概念我完全听不懂 → **`two-layer-explain`（双层解释法）**。小白版和专业版各讲一遍，再给术语对照和自测题，防止停在好像懂了。
- 这个成品做得真好，我想学它 → **`reverse-teardown`（反向拆解）**。手上得有那个范例（页面、方案、流程、看板都行），它倒推哪些关键选择拉开了差距。
- 我想系统研究这个领域 / 公司 / 技术 → **`horizontal-vertical-analysis`（横纵分析法）**。最重的一条，纵轴看它怎么走到今天，横轴看它跟对手差在哪。**必须配深度研究或联网能力跑**，否则出来的是记忆里的东西，不是研究。
- 这份材料里的说法是真的吗 → **`fact-check`（事实核查）**。也要联网。它把说法拆成事实、推论、价值判断，分五档标注，再指出推理链上最关键的漏洞。

`fact-check` 不只查事实，别人的观点和方案也能拿它过一遍。

## 三、解决问题

问题问清楚了，开始解。三条，视角一条比一条散：

- **`expert-panel`（专家会诊）**：问题本身需要几个专业配合，单一视角给不出好方案。关键在让三种视角互相质疑，真正的信息在分歧里。
- **`first-principles`（第一性原理）**：往下挖。方案上补丁摞补丁、被路径依赖卡住时，拆回基本事实重新推。改组织流程、做产品架构、修复杂系统最好用。
- **`cross-domain-borrow`（跨领域借解）**：往外找。回到本行业的本质仍然解不动，就去看别的领域，你这个问题可能十几年前就被解决过。

顺序上，**先 `first-principles`，不行再 `cross-domain-borrow`**。挖到底还是死，才值得往外扩散。

## 四、决策

前面三步给的是思路和更多可能，但路多了要选一条。

- **`steelman-both-sides`（双向钢人论证）**：两个选项都有道理。它把两边都论证到最强，然后只问一个最可能改变结论的问题。
- **`minimum-experiment`（最小实验）**：继续想已经不会更清楚了。它找出最该验证的假设，设计一个低成本、可逆、七天内能做完的实验，最后给一个明天就能做的动作。

分界线很清楚：**信息还没榨干，用钢人；信息榨干了还是选不出来，用最小实验。** 用户如果已经反复纠结过很多轮，直接给最小实验，别再陪他做一轮论证。

## 五、认识你自己

不在上面那条线上，跟具体任务无关。两条都是长对话，动辄半小时以上，都只有用户亲口叫才出现。

- **`hidden-talent`（挖掘隐藏天赋）**：往过去看，回答我身上到底有啥。从怪癖、缺点、嫉妒、无意识胜任区和能量模式里，把那些看起来毫无关系的经历拼成一份天赋说明书。
- **`life-design`（人生设计术）**：往未来看，回答我接下来还能往哪去。斯坦福人生设计方法，最后给三个完全不同、同样值得认真考虑的五年版本。

想两条都跑就先跑 `hidden-talent`，它的产出正好是 `life-design` 第三阶段要用的素材。

跑这两条之前提醒用户一句：答得越真实越具体，产出越有用，中途别跑。

## 一条铁律

这 12 条提示语在仓库里是**原文**，逐字来自作者发表的版本。你唤起任何一条时，照那段原文做事，不要改写它、精简它、或者用你自己那套流程替换它。仓库的 `scripts/sync.py verify` 就是用来拦这个的。
